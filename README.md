# traffic-video-agent

基于 AI Agent 的批量短视频生成系统——引流传单号矩阵业务。

核心能力：将行业知识/课程素材自动转化为 2-10 分钟无出镜操作演示短视频，批量产出引流内容。

## 定位

- 不依赖课程大纲，从零散素材中自动拆解知识点
- 视频时长 2-10 分钟，无出镜操作演示形式
- 内容方向：行业热点解读、基础操作教学
- 底层逻辑复用课程 Agent 能力，独立开发视频生成模块
