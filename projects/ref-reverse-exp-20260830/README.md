# 对齐测试 v1 结果（2026-08-30）

## 方法
参考视频《老赵喷车》10-48s 段 → demucs 分离（PC GPU, 8.5s）→ VAD 句级锚点（-34dB/0.30s）→
IndexTTS 2.5 零样本克隆（参考音频=原句干声，3句×3档 duration_factor 0.85/1.0/1.15）
→ atempo 精修（残差≤25ms）→ amix 混回伴奏（adelay 摆位 0s/17s/28s）。

## duration_factor 实测（TTS 总时长 s，目标 A=4.0 B=7.0 C=9.0）
| cue | 0.85 | 1.0 | 1.15 |
|---|---|---|---|
| A | 4.24 | 5.11 | 5.87 |
| B | 6.71 | 8.22 | 9.00 |
| C | 6.92 | 7.06 | 8.90 |

规律：df 档位影响不稳定（C 句 0.85/1.0 几乎同长），不能只靠 df 档位选点——**生成后实测时长 + atempo 收口**的两步法成立，每句独立选档。

## atempo 收口精度
A +3ms / B -25ms / C -24ms（一轮反算内收敛）。

## Gemini 盲检混音轨
- 3 句落点 0s / 17s / 28s，与摆位一致
- 人声卡 BGM 留白、无打架
- 音色戏腔与全片风格统一
