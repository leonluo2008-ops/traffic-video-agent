# 说话人界定实验报告（甲方案 · 2026-08-30）

## 四证源实测结果

### ① VAD 边界（silencedetect -36dB/0.22s）
9 块全部客观准确，**时间起止的唯一权威**。缺陷：长块多角色粘连（块1 8.5s 含 3 角色）。

### ② 声纹聚类（MFCC20+delta 互近邻余弦距离 + 层次聚类，纯 numpy 无 torch）
- 装机：`/tmp/speakerlab` venv（python_speech_features + scipy，**resemblyzer 因 torch 下载超时放弃**）
- k=3 结果：A={0,1,2,7} B={5,6,8} C={4群杂}
- **有效性**：成功把群杂（块4）独立成簇✓ 同角色块聚在一起✓
- **局限**：块8(华安)与块5,6(对穿祥)同簇——男声戏腔 MFCC 区分度不足；块7(对穿祥)聚进A(宁王组)
- 结论：**能分"非同类音色"，同类戏腔男声不可靠**。生产建议 pyannote/embedding 模型，MFCC 只做兜底

### ③ 视觉口型锚定（语音块中点抽帧×2 → 拼网格 → Gemini 判读）
- **大坑1（已踩）**：抽帧时间忘记加段偏移 10s → 全部判到无关画面. **块时间→原片时间必须 +offset**
- **大坑2（已踩）**：字幕裁切坐标猜错两次（y=850/860 全黑），最终靠像素亮度扫描定位内容区 y=200-720、字幕在 y≈655-725
- 判读结果：长块可靠（块0=宁王✓ 块5/6=对穿祥✓ 块8=华安✓），**短块/边界块不可靠**（块2 抽帧落在镜头切换边界，把残留字幕当本块字幕）
- 结论：**每块至少抽 3 帧（25%/50%/75%）+ 只信多数一致**；字幕是最强辅助证据（电影自带烧录字幕）

### ④ 字幕 OCR
- 内容区电影画面自带字幕（本片是二创重新压的字幕）→ **字幕文字=台词的最强客观锚**
- 块0"本王带车企护主犬"（自称本王→宁王）块5"一民、二徒"→上联属对穿祥侧，全部与转录吻合
- 中点抽帧在块尾/块头会读到相邻字幕 → 抽 25%/50%/75% 三帧取交集

## 合并裁决规则（实验验证后的定稿）
1. **时间起止** = ① VAD（唯一权威）
2. **说话人身份** = ③ 视觉（长块）+ ④ 字幕语义（自称"本王"等铁证），②声纹做"同一人/不同人"校验，④与③矛盾时以字幕语义优先
3. **长块粘连** = 必须子块拆分（块1 用 -36dB/0.22s 已能拆出子句，但块内角色切换点需②+③联合）
4. **短块(<1s)身份** = 邻块声纹相似度 + 上下文（④④逻辑），禁止只用视觉单证

## 甲方案结论
四证源合并可行，**时间轴问题已根治**（VAD 客观边界+字幕交叉验证），**角色命名漂移已根治**（字幕语义锚定+视觉长块判读）。块1 类"长块多角色粘连"仍需子块拆分工序——整合进新工作流时作为"分镜分析阶段"的子步骤。

## 生产工作流修订建议（分析阶段输出契约 v2）
```
输入: 完整视频
1. demucs 分离 → vocals/no_vocals
2. VAD 两级细锚点 → 语音块表
3. 长块(>3s)子块拆分 → 子块表
4. 每子块: 字幕条 OCR(裁 y=内容区底部) × 3帧 → 文字证据
5. 每子块: 口型抽帧判读 × 3帧 → 视觉证据
6. MFCC/声纹聚类 → 簇ID证据
7. LLM 合并裁决 → 最终分镜总表(角色锚定字幕语义)
8. 产出: {block_id, start, end, role, text, decision, evidence} per 子块
输出后: 填词 → TTS → 对齐 → 混音（此前已验证）
```
