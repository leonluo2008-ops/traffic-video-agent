# v7 方法论转向：精准时间轴优先（2026-08-30 深夜拍板）

## 用户裁决原话（2026-08-30）

> 我觉得这个还是不行。Whisper 首先应该拆解出一个非常精准的音频时间轴，原始材料要能够很精准的对齐音频。

## 总原则（v7 三步铁律）

1. **拿到精准的音频和时间轴的对照表**——字级/短语级时间戳，不是句级猜测
2. **按照这个对照表来填词**——填词服从时间轴（每字每句落在实测槽位内），不是时间轴迁就填词
3. **使用对应时间轴的原音频做参考，生成新的填词音频**——参考件与槽位一一对应，TTS 直接生成到槽位时长

## v6 失败根因（为什么"还是不行"）

- v5/v6 的时间轴是「画本标注 → ASR 句级校正」的混合产物，槽位边界来自**标注+校正**，不是纯实测
- 句级 ASR（Whisper segment）的 start/end 本身有 ±0.3-0.8s 漂移，对联混战区重叠话轮更没法切
- 结果：26 槽被"纠正"过仍然不同步——**校正的方向反了：应该是时间轴生地基，槽位表在时间轴上生长**

## v7 新路线（待调研验证）

```
原片音频 → WhisperX (large-v3 转写 + wav2vec2-zh 字级强制对齐)
         → 字级时间戳对照表（每字 start/end，ms 级）
         → 短语级聚合（VAD 边界 + 停顿检测，每短语 start/end/dur/字数）
         → 填词层：按短语槽位字数/时长填新词
         → TTS 层：该槽位原音频做参考件 → IndexTTS 生成 → atempo 微收口
         → 贴回
```

关键转变：**对照表是唯一事实源**。画本标注降级为内容参考，不再参与时间轴定义。
