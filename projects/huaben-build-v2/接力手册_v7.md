## 五、关键技术事实（踩坑记录，别再踩）

1. **Unicode 码点念读**（v7 新坑）：payload 双层 json.dumps 会把中文转义成 `\u4e7e`，TTS 照念码点。**正确姿势：payload 写 UTF-8 文件，scp 过去，`curl -d @file`**
2. **scp 目录传 Windows**：OpenSSH Windows 端不支持 `/.` 尾缀写法，用 `scp -r 目录本体`
3. **IndexTTS ComfyUI 收件**：SaveAudio 产物在 `D:/AI-tool/ComfyUI-aki-v1.6/ComfyUI/output/`，文件名带 `_00001` 后缀，从 history API 拿确切名
4. **duration_factor 范围 0.5-2.0**，超限靠 atempo 收口；r=1/r 预估不准（生成时长非线性），二轮补偿实测改善率 56/57
5. **WhisperX batch 丢标点、VAD 边界是网格**：两 dump 必须 difflib 融合（l2v4_fusion.py 已验证）
6. **glm-5.3-flash 长文本 JSON 空回**：逐槽调用（≤15 字）不一次全表
7. **PC 关机**：测试完远程关机（用户拍板）。PC=100.109.238.27，ssh key=~/.ssh/pc_luo1_ed25519
8. **v6 资产可继承**：orchestrator.py（Demucs+混音三轨）、slots_v3（spk 标注）
