## 四、关键技术事实（踩坑记录，别再踩）

1. **WhisperX batch 模式丢标点、段层退化**：align_dump.json 只有 7 大段、无标点；VAD 模式（transcribe_dump.json）43 句带标点但边界是 VAD 网格（0.88→5.88→8.88 整数串）。**两个都要跑，靠 difflib 融合**（l2v4_fusion.py 已验证：相似度 0.748 → 76 槽）。
2. **CTC 字流零间隙**：段内字尾→下字头间隙 = 0（430/436），不能靠字间隙找短语边界。
3. **两个 ASR 错字版本不同**（“十口心似”vs“石狗新四”），字面窗口搜索会失效，必须全文 difflib。
4. **glm-5.3-flash 长文本 JSON 输出空回**：101 字段两次空回，72 字段成功——L3 填词时逐槽调用（≤15 字），不要一次全表。
5. **PC 关机前记得**：PC (100.109.238.27) 测试完远程关机（用户拍板）。
6. **L2v4 off-by-one 已修**：b_cursor = b1+1，槽间无重叠（修复后 76 槽 / 87% 覆盖 / max 3.6s）。
7. **v6 资产可继承**：v6 slots_v3（56 槽含 spk 说话人标注）可与 v7 槽位 difflib 对齐，继承说话人归属；v6 的 IndexTTS + atempo 收口 + ffmpeg 贴回全链路已验证。
