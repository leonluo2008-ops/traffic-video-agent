## 一、流程复盘：v5 → 校准 → v6 的完整链路

### 已完成工序
1. **v5 全量成片**（36 TTS 槽 + 17 KEEP 槽 + 3 直用区）：画本锁版 → TTS 生成（df=0.5 重生 5 槽）→ atempo 收口 → 三层混音 → 合回画面。产能：36 槽 13min（RTX 5070 Ti）。
2. **v5 验收缺陷**：音色情绪过关，**口型时间歪**——slots 时间戳全是画本标注值（0.1s 粒度整值），从未做过音频实测。
3. **WhisperX 校准**（PC GPU）：large-v3 转写 + wav2vec2 zh 字级对齐。拼音窗口匹配 + 原声区禁全局兜底 → 44/53 对齐，中位位移 +0.085s，20 槽锚点被实测纠正（最大 N47 +8.0s、N39 +7.4s）。
4. **v2→v3 数据契约修正**（本轮）：dur 派生重算 / KEEP 槽只读保护 / 低质匹配降级 ASR 段边界 / 全局单调+零重叠闸门 / 对联混战区证据表裁决 / 语速闸门。**53 槽全过，ERRS NONE**。

### 复盘结论
时间轴问题的本质不是"标注不准"而是**数据契约缺失**：start/end/dur/槽边界/直用区五者互不校验，谁改谁都可能破坏他人前提。v6 把契约写成代码（fix_slots_v3.py），机器闸门全过才算数据就绪。

## 二、流程规范（v6 起生效，同素材禁止违反）

### 规范 1：时间轴数据契约（五闸门）
数据就绪 = fix_slots_v3.py 全绿：
1. **dur 派生**：dur = end − start，改边界必重算
2. **KEEP 只读**：人工审核过的槽，机器只在高置信（cover≥0.75 且 span∈[0.5,1.67]×原dur）才可微调，否则回退标注
3. **低质降级**：TTS 槽 cover<0.6 或 span 比出 [0.5,2] → 锚 ASR 段边界
4. **全局一致性**：零重叠 + 单调（按 start 排序后逐对检查），冲突先中点切分，倒挂/簇矛盾整体回退标注值 + needs_review
5. **语速闸门**：TTS 字数/dur ∈ [1.2, 8] 字/s，出界 flag 人审（N05/N06 是画本既定处置，除外）

### 规范 2：分区治理（同素材三区各有铁律）
- **常规对白区**（0~117s）：拼音窗口匹配可靠，机器实测优先，微小修正直接吃
- **原声区/runs**（N21~N33 蒙太奇等）：人工标注为准，机器不碰；run 边界槽只影响拼接缝
- **对联混战区**（117~181s）：槽↔ASR 非 1:1（复合槽、漏收、同音错字），**证据表硬裁决**，每条标 ASR 沔来源，争议 needs_review

### 角色规范 3：角色扮演是政治不正确的产物（v6 新增，源自 N46）
画本把 [160.74~162.46]「鱼肥果熟入我肚」标成「群众chanting」——真实身份是**对穿肠的正式台词**，与 N44 后半「我家坟头来种树」是同一副对联的两句。任何"群众/杂"标注出现时：
1. 先查 ASR 全段——有清晰可读台词 = 不是群众，按台词槽处理
2. 拼音对齐画本 orig——能对上 = 原画本结构错，进 needs_review
3. 录入证据表留档

### 规范 3：交付纪律（重申）
- 交付物 = **完整成片 + 对照表**，禁止切片式渐进交付
- 每次时间轴/填词升级后必须主动补拼装成片交付，不等用户问
- 产物在 PC 上时给路径不拉回（带宽留给大件）
- 产物路径规范：PC `D:\AI-tool\huaben-build-v2\` 下按 子目录/{refs,tts_out,tts_fit,mix}

### 规范 4：PC 协作纪律
- SSH 长任务零回显≠卡死（stdout 全缓冲）；探测三件套：ComfyUI /queue、产物目录计数、落盘时间戳
- Windows 端 Python 一律 `-X utf8`；pip 装包走清华镜像；引号转义坑 → 脚本文件 scp 上去跑
- LoadAudio 平铺文件名；整数槽位索引；必填项 lang/duration_factor/filename_prefix；产物键 audio+gifs 双查

### 规范 5：复盘节奏
- 每个里程碑（数据契约绿 / 成片交付 / 用户验收）各做一次微型复盘，新坑入 skill
- 契约脚本独立可重跑（fix_slots_v3.py 无状态，输入 slots.json+slots_v2.json+transcribe_dump.json，输出 slots_v3.json）
