## 0. 执行摘要

**用户三步总原则技术上都成立，且各步都有成熟开源工具支撑。推荐路线：WhisperX 字级对齐打底 + IndexTTS-2 duration_factor 生成 + atempo 微收口。** 关键洞察：三步原则的**顺序**是护城河——先表后词、先词后声，任何一步颠倒都会重蹈 v5/v6 覆辙。

另外本机 PC 已实测验证第一步（437 字级时间戳，中位 score 0.927），路线可行性有直接证据。


**三个关键实测发现（写进 v7 设计的核心输入，已按对抗审计修正）：**

1. **Whisper 段层退化**：batch 模式下 segment 层只剩 7 段大块（最长 28.1s），不可用作短语边界——v6 用的正是这种段级边界，这是口型不同步的直接根因之一。**短语切分必须从字流推导。**
2. **CTC 字流段内零间隙**：段内字尾→下字头真实间隙 = 0（430/436 处），只有 6 个段间大间隙（1.46-31.22s）。初版报告“188 个 0.15-0.25s 间隔 / 50 个 >0.4s 停顿”是字起始间隔误算，已修正。
3. **旧 VAD dump 带标点（审计决定性发现）**：transcribe_dump.json（VAD 模式 43 句）带完整中文标点，是短语语义边界的正确来源；batch 模式（align_dump）丢标点。**v7 正解 = 双 dump 融合**（VAD 标点句 × batch 字级时间戳，difflib 全文对齐）。

### 2.2 与 v6 管线的差异

v6：标注 dur → TTS → atempo 拉到标注 dur（目标错 → 全错）
v7：字级实测 dur → 填词（字数对位）→ duration_factor 初调 → atempo 收口到实测 dur（目标真 → 结果准）

## 2.3 补充调研发现：反向路径（知识盲区补全）

调研中发现一个值得记录的反向路径：**Audio-to-Audio VC（声音转换）**——直接用原音频做输入（保留原时长、韵律、口型节奏），只换音色。代表：seed-vc / so-vits-svc。**填词场景不适用**（要换内容，不是只换音色），但“口型节奏 100% 保留”的特性值得记入未来 spike：若 v7 TTS 路线口型仍不同步，可评估“填词文案→同槽位说话人 TTS 定韵律→VC 换音色”的混合路线。

**关键验证：用户三步原则与业界最成熟的两个开源管线（VideoLingo、Linly-Dubbing）核心架构一致**——都是 WhisperX 字级时间轴做地基。差异点（也是 v7 的本土化创新空间）：
- 它们是**翻译**（内容长度被动），v7 是**填词**（内容长度可主动设计——字数对位约束）
- 它们用 NLP 断句切分短语，v7 用字间停顿+标点+能量三信号（对联混战区重叠话轮必须更细）
- 它们的 TTS 源音频参考 = 整片人声，v7 用槽位原声做参考（音色锚定更强）

### 3.2 可直接借鉴的工程细节

- VideoLingo 的 **NLP 断句**（语义+标点融合）可借鉴到 v7 短语聚合
- Linly-Dubbing 的 **Demucs 人声分离**值得做前置（对联混战区的背景乐/群杂分离，提升对齐质量）
- VideoLingo 的 **3-step 翻译**理念映射到填词：初填→反读校验字数/时长→润色（v6 的填词槽位表思路可升级）

## 4. v7 管线设计提案（待审计）

```
【v7 五层管线】(以字级对照表为唯一事实源)

L0 音频底座: 原片 → 16kHz mono wav (已有)
L1 字级对齐: WhisperX large-v3 + w2v2-zh → 字级时间戳流 (437 字, 已实测 23s)
L2 短语聚合: 三信号融合切分
   信号A: 字间停顿 (>0.4s 候选, 50 个)
   信号B: 标点 (Whisper text 的 ,。!? )
   切分规则: 停顿+标点双确认 → 硬边界; 单信号 → 软边界(留填词层判断)
   信号C: 能量验证 (静默<-35dB 硬切; 背景乐填充 → 垫底层; 连读 → 不切)
L3 填词层: 每短语槽位 (start/end/dur/字数/能量类型) → LLM 填词
   硬约束: 字数对位 (叠字对叠字) + 韵脚对齐 (对联特性)
   软约束: 韵律节奏 (字间隔分布)
L4 TTS 层: 槽位原声做参考 → IndexTTS-2.5 (duration_factor 按槽 dur/生成dur 自适应)
   → atempo ±15% 收口 → 贴回
```

**与 v6 的本质区别**：对照表（L1+L2）是唯一事实源，填词和 TTS 都消费它；v6 是画本标注当事实源、ASR 当校验——方向反了。
